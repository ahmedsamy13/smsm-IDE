# Real fullstack demo

Run npm ci once, then npm run dev. Open http://127.0.0.1:5173. Both servers bind only to this machine. Stop with Ctrl+C in the task terminal.

Scripts: dev, build, start (backend), typecheck, lint, format. Tasks persist under .data; verification uses a separate DATA_FILE. See API.md for the contract and postman/ for runnable API checks.
